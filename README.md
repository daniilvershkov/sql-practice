# SQL practice

Практика SQL на тестовой банковской базе: таблицы `clients` и `loans`.

## Файлы
- `clients and loans.sql`: создание таблиц и тестовые данные
- `task1.sql`: ORDER BY, LIMIT, IN, LIKE, GROUP BY, HAVING, NULL, COUNT DISTINCT
- `task2.sql`: INNER JOIN, LEFT JOIN, условие в ON и в WHERE, JOIN + GROUP BY + HAVING
- `task3.sql`: FULL JOIN, self join, UNION / UNION ALL, CASE WHEN, доля дефолтов

## Инструменты
PostgreSQL, DBeaver

## План
Дальше: работа с датами, подзапросы и CTE, оконные функции.
